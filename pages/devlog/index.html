Story about build a Lotus Agenda clone (with extras)

The start of something

2026-10-08 · Mattias Jämting

So, back in the 00's i got hooked on a application for DOS called Lotus Agenda.

I was playing around with it because i couldnt really understand what it did. It was ... wierd. My memories of it are like solving a mystery.

But suddenly something clicked and i suddenly found it really useful. I used for a while, but the disadvantages of it being an old DOS application made it hard to stick to it.

Since then the memory of it never fully disappeared and i kept it on a DosBox instance on my mac.

A few weeks ago while playing with Claude i thought it could be a fun ond useful exercise to try recreating it, using Elixir which is a language i'm currently studying and finding it to be real good.

So in this blog i´ll document the journey. It has been a fun and interesting experience.

/Mattias
