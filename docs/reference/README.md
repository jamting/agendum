# Reference material

- `US5115504.pdf`: US patent 5,115,504, _Information Management System_ (Belove, Drake, Kaplan, Kapor, Landsman, Zagieboylo; Lotus, 1992). Describes Agenda's data model: items, categories, independent link structures, subsumption, views with sections and columns, automatic assignment, and ambiguity resolution.
- `AGENDA_MENUS.md`: Agenda 2.0's F10 menus as it shows them (the view's, the note editor's, the category manager's), each command with its help line, walked in Agenda run headless (`tools/agformat/agenda_driver.py`, 2026-10-15). The first place to look for a menu path or a command name.
- `agenda_menus.json`, `agenda_boxes.json`, `agenda_key_bars.json`, `agenda_messages.json` and `agenda_message_pairs.md`: Agenda 2.0's menus, settings boxes, key bars and messages, captured from the program run headless (`tools/agformat/`); the parity tests compare Agendum with them. The menu words and the help lines are Lotus's text.

The other reference material this project was built with is not included here, as it is not ours to publish: Lotus Agenda 2.0's manuals (at https://archive.org/details/lotus-agenda-users-guide), Agenda's F1 help, Lotus's support Q&A, the starter applications, and articles about Agenda.
