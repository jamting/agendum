# Reference material

- `US5115504.pdf`: US patent 5,115,504, _Information Management System_
  (Belove, Drake, Kaplan, Kapor, Landsman, Zagieboylo; Lotus, 1992). Describes
  Agenda's data model: items, categories, independent link structures,
  subsumption, views with sections and columns, automatic assignment, and
  ambiguity resolution.
- Lotus Agenda 2.0 manuals (User's Guide, Quick Start, Setting Up Agenda,
  Starter Applications, Working with Definition Files, Working with Macros):
  https://archive.org/details/lotus-agenda-users-guide. Their plain-text OCR
  is in this folder (`*_djvu.txt`). The PDFs (`*_text.pdf`) are git-ignored;
  download them from archive.org and put them here if you want them.
- `Agenda 2.0 Help File.html`: the complete Agenda 2.0 Help (F1) as HTML,
  including the key charts for views, notes, the category manager and the
  macro editor ("Agenda Key and Menu Charts"), every settings box, and short
  how-to topics. The best quick check of a key or a box's settings.
- `ag2qanda.txt.html`: Lotus technical support questions and answers about
  Agenda 2.0 (1990–91): known bugs fixed by the Update Kits (recurring dates,
  datebook views, structured files) and how features behave in practice.
- `AGENDA- A Personal Information Manager (PIM).md`: Kaplan, Kapor, Belove,
  Landsman, Drake, "Agenda: A Personal Information Manager", _Communications
  of the ACM_ 33(7), 1990, as text (references to illustrations removed). The
  designers' own account: what personal information is, items and
  categories, views, automatic assignment and why users accept the program
  acting on its own.
- `Hidden Agendas, Lost Cities - System Stack.md`: an essay from the blog
  System Stack on using Agenda today (on a Pocket 8086 and in DOSBox-X):
  what it does that modern task managers (Todoist, OmniFocus …) don't, set
  against Getting Things Done's fixed "places", with links to further
  material (Tavis Ormandy's tour, Bob Newell's FAQ, Tools for Thought).
  Background on why the program still matters to people.
- `1557.full.pdf`: Shea, Gordon, Hawkins, Kawchuk, Smith, "Pathology in the
  Hundred Acre Wood: a neurodevelopmental perspective on A.A. Milne",
  _CMAJ_ 163(12), 2000, 1557–1559. A tongue-in-cheek paper ("Research of the
  Holiday Kind"), behind the diagnoses in the Easter egg `agendum --pooh`
  (`Agendum.Starters.Clinic`), which disagrees with some of them.
