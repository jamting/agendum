### § 5 Update defaults, as Agenda does it

Agenda's File Properties box has an Update defaults row: it takes the current file's settings and makes them the starting point for every new file. Agendum does not have it yet; it is one of the last three F10 commands missing (`docs/plans/AGENDA_PARITY.md`). Where should the defaults be kept (the person's preferences, ADR 0008?), which settings do they include, and does the command behave exactly as Agenda's?

### § 6 The owner's own defaults for new files

The owner wants their own defaults for new files, such as the date format: a new file shows Agenda's MM/DD/YY (R41), while the owner types dates in Swedish. Is Update defaults enough for this, or should more be done, such as a built-in date format that follows the date language? And which ways of making a file should use the person's defaults: an empty new file, the starters, the demo, the Thoughts file, an `.AG` import?
