## § 6 A "next-level TUI": a second terminal program with modern keys?

Tabled at the meeting of 2026-10-21-2324 (§ 9): the owner pictured the core and the terminal program as the clone, with a "next-level TUI" and the web version as other things using the core. A terminal program with modern keys would change ADR 0038, which put modern keys and the person's own keys in the web only. To decide: is there to be one, and how does it relate to the clone's Extras switch (ADR 0043) and the web's modern interface?
