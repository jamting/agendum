# Plan: Agendum as close to Agenda as it makes sense (2026-10-15)

**Status:** **done**: the truthful clone was declared done on 2026-10-26 with v0.62.0, every required step built and both lists' tags confirmed by the owner (meeting 2026-10-26-1108, § 7). The plan stays as the record of the clone: its lists are the accepted differences, and a new difference from Agenda passes ADR 0043's test or goes behind the Extras switch. The optional steps went back to the roadmap, each in its area.

**The test for a difference** (ADR 0043, meeting 2026-10-21-2324, § 6): a difference from Agenda 2.0 stays only if **the machine** forces it (keyboards, terminals, sound, files), it protects **the person's work** (undo, asking before changes are lost), or it is **quiet** (an Agenda user who never asks for it never meets it: nothing changed on Agenda's screens, no Agenda key taken, no entry added to Agenda's menus). Anything else is an *extra*, hidden behind the Extras preference (off by default), or is changed back. Each entry on the two lists below has its tag (*machine*, *work*, *quiet*, *extra* or *change back*), confirmed by the owner entry by entry on 2026-10-22; a change back that alters a habit is a roadmap item of its own, settled first. The comparison with Agenda's captured menus (meeting 2026-10-21-2324, § 8) reads these tags as the accepted differences.

The ambition: someone who knew Lotus Agenda 2.0 sits down at Agendum and finds the same screen, the same keys, the same menus and the same behaviour, apart from a list of **accepted enhancements** (things Agenda did not have) and **accepted modifications** (things Agenda had that Agendum does differently, for a reason). Everything else that differs is a gap, to be closed or moved onto one of the two lists on purpose.

This overview starts with the main control panel (the two top lines, the key bar and the F10 menu), checked in the real Agenda 2.0 run headless on a copy of PLANNER (2026-10-15: every menu level walked without running a command; the view's screen read) and its F1 help ("About Indicators", "Mode & Message Indicators", "View Indicators"). The note editor has its own plan: [`NOTE_EDITOR.md`](NOTE_EDITOR.md). Agenda's menus as they are, for reference: `docs/reference/AGENDA_MENUS.md`.

Out of scope, as SPEC §6 says: printing on paper and print preview (F10 Print and everything under it), typesetting (fonts, attributes), networks and file reservations, application protection, the macro command language, DOS itself (System, Compress).

## Beyond Agenda: accepted enhancements

What Agendum has that Agenda did not. The entries tagged **extra** are hidden while the Extras preference is off, as it is by default (R77, built 2026-10-23). Each entry carries its tag by ADR 0043's test, proposed by Claude and confirmed by the owner entry by entry in the tagging sitting of 2026-10-22 (meeting 2026-10-22-2130, § 5b): **machine**, **work** or **quiet** stay; **extra** is hidden behind the Extras preference; **change back** is a roadmap item of its own (ROADMAP, Towards parity).

- **work** · Undo and redo of every change (CTRL-Z, CTRL-Y; R30), on their keys only since the menu took Agenda's shape (2026-10-24).
- **machine** · JSON export and import (R44), a readable file format.
- **extra** · Calendar subscriptions (iCal, R45) and time zones.
- **quiet** · Date languages, Swedish among them (R41): English is the default.
- **quiet** · Colour themes beyond Agenda's (R40): Agenda's colours are the default.
- **machine** · Word wrap in the note editor (R64). Agenda wrapped notes too, at 79 characters (User's Guide, importing a note); Agendum wraps at the window's width, the same on an 80-column screen.
- **machine** · A count before a command in a view, as Emacs's numeric prefix: ALT-1 ALT-0 ↓ moves ten rows (R65). In Agenda ALT-digits typed DOS character codes, which a terminal cannot.
- **quiet** · Help made from the commands and keymaps (R65): behind Agenda's help (R65e), F6 Keys lists every key and leads to **Commands you can run here** (those that cannot run now greyed, with the reason, R65a; each with a longer text saying why one would use it, R65b) and **Describe a key**.
- **quiet** · The debug log and the developer tools (ALT-?).
- **extra** · Descriptive key bar labels on a wide screen.
- **quiet** · The `--clinic` Easter egg (reached only by a command-line flag).
- **extra** · ► before the current view in the view manager, and F5 to list the views by recently used (R68).
- **extra** · A "While you were away" box for alarms that came due while the file was closed (R70). Agenda rings such alarms when the file is opened and shows `@`, with no box (checked in Agenda 2.0, 2026-10-22: an alarm due at 10:04pm, the file closed, opened at 10:05pm); the items are in Utilities ▸ Show Alarm's Past Alarms (R38).
- **extra** · Zettel ids (Quadsyl-24, R73, ADR 0039), a Zettel id column (R73a) and links between items (R73b).
- **extra** · A micro-blog published from the file (File ▸ Transfer ▸ Publish, R74).
- **extra** · Feeds: a plain RSS and Atom reader, the News view, OPML, CTRL-V to open a link (R75).
- **extra** · Ingested categories: a feed's or calendar's categories are the extra's, not changed by hand, the Feeds family folded in the category manager; F2 in the Feeds and Calendars boxes renames (R75a, 2026-10-26).
- **extra** · Completion offers the person's own categories before the ingested ones, an exact name still first (R32, R75a, 2026-10-30).
- **quiet** · The Extras row in File ▸ Customize (R77): the switch that hides every entry tagged *extra* above, off by default (the owner chose the Customize box and confirmed the tag, 2026-10-23). A row Agenda's Customize box did not have, met only by someone who opens Customize and looks for it.
- **quiet** · ALT-↑ and ALT-↓ in View Properties' Sections (R78) move the highlighted section a place at once, as they move a column in Section Properties; Agenda's ALT-F10 (pick it up, ↑ ↓, ENTER) works as well (the owner chose both and the tag, 2026-10-23). Keys Agenda's box did not use, met only by someone who presses them.
- **quiet** · CTRL-X runs a command by name, found by part of it or its initials, in a small box (R65d, ADR 0040), a key Agenda left unused; the command list narrows the same way.

Off the list since the tagging sitting, as no difference from Agenda: **search** (ALT-F6, ALT-N / ALT-P and the Show View for results) is Agenda's own ALT-F6 SEARCH in views and notes, with its Match show view (Agenda's F1 help); comparing it with Agenda's Search box is parity work (ROADMAP). **Hide column heads** (R57) is a setting of Agenda's own View Properties box (checked in Agenda 2.0, 2026-10-22).

## Done differently: accepted modifications

What Agenda had that Agendum does another way, on purpose. Tagged as the enhancements above, 2026-10-22. Both lists' tags were confirmed by the owner, entry by entry, at the meeting of 2026-10-26-1108 (§§ 5–6); the change backs done since (the category lists, R81b; Write giving way to MakeCopy, R82) are off the list.

- **work** · **Saving.** Agenda saves automatically (Quit, Retrieve). Agendum keeps changes until you save and asks before they are lost; ` *` on the File line shows unsaved changes.
- **work** · **Erase moves the file to the Trash** (File ▸ Maintenance ▸ Erase, R82; the owner's choice, 2026-10-25): Agenda deleted it from the disk; Agendum puts it in the system's Trash, where it can be got back.
- **machine** · **External note files** (Agenda's note editor ▸ File ▸ Attach, Detach, Erase, and ♫; left out on purpose, meeting 2026-10-25-2252, § 5). Notes live in the Agendum file. Agenda's reasons were DOS-era limits (file size, notes over 10,000 characters, memory); a note kept in a local file could not be reached by the planned web version. Attaching files of any kind (images, a CV) is an idea for after the clone (ROADMAP, Ideas).
- **machine** · **Sounds** (R76). Agenda's own tones, through the computer's audio player rather than the PC speaker (the terminal's bell where there is none); every error message beeps with the one error beep, where Agenda also had a shorter one; Sound in File ▸ Customize silences them all.
- **Boxes** (ADR 0030): ENTER keeps and ESC cancels in every settings box, as Agenda's frame says, so that part is no difference. Checked in Agenda 2.0, 2026-10-22, one difference remains; the other two found then were changed back (changes apply on ENTER, v0.29.0; the category lists, R81b):
  - **work** · ESC in a box puts back everything done since it opened, changes made in its category lists included; Agenda's ESC kept those.
- **work** · **Retrieve** asks about unsaved changes.
- **machine** · **A crash keeps the unsaved changes** (R82b, 2026-10-26): Agenda's Damaged File box (DMGD!) offered to save the changes to `MYINFO@.AG`, to be repaired with DB2STF; Agendum, which stops on a crash, writes them to `notes@.agendum` itself and offers them when the file is next opened.
- **machine** · **CTRL keys** for INS, HOME, END and the most used commands (CTRL-N new, CTRL-E edit, CTRL-K done, CTRL-D discard, CTRL-S/O/P/Q save, open, print, quit; R31, KEYBOARD.md), as Mac keyboards lack those keys and terminals can map ⌘ shortcuts onto them. Function keys are required, as in Agenda: there is no ESC + digit stand-in (ADR 0032).
- **quiet** · **Where you left off** (R69, meeting 2026-10-16-1905, § 5): Agenda stored the current view and item in the file; Agendum keeps them in the preferences per file, so moving does not change the file and each person (later, each user) has their own place.
- **machine** · **No CTRL-ENTER in boxes** (Agenda's "clear the setting", User's Guide 2-17; the owner, 2026-10-24): terminals send CTRL-ENTER as ENTER. F8 clears a setting whose default is empty; F2 then CTRL-U otherwise.
- **machine** · **The ALT, CTRL and SHIFT key bars come with ALT-K, not by holding the key** (meeting 2026-10-24-2057, § 5; the tag confirmed by the owner 2026-10-24: ALT-K is Agenda's own key, so not quiet; built, R80): a terminal sees ALT or CTRL held alone only with the kitty keyboard protocol (`archive/KITTY.md`), so ALT-K cycles the bar through the normal one, ALT, CTRL, SHIFT and hidden; the key names (`AltF4`, `CtlF4`) say which (a letter in the last column, decided at the meeting, was dropped by the owner after trying it, 2026-10-24).
- **change back** · **An item's text cannot be empty** (found 2026-10-31; the tag confirmed by the owner, 2026-10-31): Agenda takes an emptied text, the item staying with none; Agendum says "Item text cannot be empty (use ALT-F4 to discard)" while the line is still open. To be built Agenda's way (ROADMAP, Fixes and polish).
- **work** · **GETITMS discarding the open note's own item closes the note** (v0.72.7; the tag confirmed by the owner, 2026-10-31): as in Agenda the item goes to the trash with its note, the pasted text included; Agenda's note stayed open until left, Agendum's closes at once, so nothing more is typed into an item already in the trash, where it could be lost when the trash is emptied.
- **machine** · **Export / Import** are JSON, not structured `.STF` files; Import also reads Agenda's own `.AG` files (R72); STF is still to come (ROADMAP, Data interchange).
