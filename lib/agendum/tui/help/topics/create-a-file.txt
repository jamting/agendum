Create a File

PURPOSE       Start a new, empty file.

STEPS         1. F10 File Retrieve (or CTRL-O).
              2. Type a name that is not a file yet, and ENTER.
              3. In the New File box, a Description and a Password
                 if you want them; ENTER.
              4. Save it (CTRL-S) when you are ready.

NOTE          A new file has MAIN, Entry, When and Done, and an
              Initial View with one section to start typing in.

SEE ALSO      **Description and Password for a New File**
              **New File Box**  **Files**
INDEX         Files > Create; New > Files; Create > Files
