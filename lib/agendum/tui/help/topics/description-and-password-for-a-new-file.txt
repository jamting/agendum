Description and Password for a New File

PURPOSE       Say what a file is for, and keep it private.

DESCRIPTION   Up to 40 characters, shown beside the file's name
              when F8 lists descriptions in the Select File box.
              Change it in File Properties, File description.

PASSWORD      Up to 12 characters. The file is saved encrypted, and
              opening it asks for the password. A forgotten password
              cannot be recovered: there is no other way in. Change
              or remove it in File Properties, Set file password.

SEE ALSO      **New File Box**  **File Properties Box**
              **Password Box**
INDEX         Files > Description; Files > Password; Password > Files
